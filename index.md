# 🏛️ Enterprise Identity Architecture Program  
A complete **20‑day hands‑on learning journey** covering Microsoft Entra ID, Zero Trust, Identity Governance, Conditional Access, PIM, Automation, Monitoring, DR/BCP, and enterprise‑grade architecture documentation.

This program is designed as a **portfolio‑ready identity engineering curriculum** aligned with SC‑300 exam domains and real‑world IAM architecture practices.

---

## 📘 Program Overview

This repository contains:

- 20 days of structured identity engineering labs  
- Enterprise architecture deliverables  
- Governance models  
- Zero Trust identity design  
- Automation pipelines  
- Monitoring dashboards  
- Disaster recovery & continuity plans  
- Identity maturity model  
- Future work roadmap  

Each day builds on the previous one, forming a complete identity architecture portfolio.

---

## 📂 Repository Contents (20 Days)

### **Day‑01 — Identity Fundamentals & Tenant Setup**  
Folder: `01-Identity-Fundamentals/`  
Learn core Entra concepts, RBAC, and identity foundations.

### **Day‑02 — Conditional Access Foundations**  
Folder: `02-Conditional-Access/`  
Implement MFA, session controls, device filters, and baseline CA.  
Reference: [Conditional Access](ca://s?q=Create_Conditional_Access_policy)

### **Day‑03 — Identity Lifecycle Management**  
Folder: `03-Identity-Lifecycle/`  
Users, groups, roles, provisioning, lifecycle governance.

### **Day‑04 — App Registrations & Enterprise Apps**  
Folder: `04-App-Registrations/`  
OAuth2, OIDC, SAML, app roles, permissions.

### **Day‑05 — Modern Authentication Flows**  
Folder: `05-Modern-Auth/`  
Token flows, API permissions, app integration.

### **Day‑06 — Identity Protection (Risk‑Based Access)**  
Folder: `06-Identity-Protection/`  
User risk, sign‑in risk, remediation.  
Reference: [Identity Protection](ca://s?q=Explain_Azure_AD_Identity_Protection)

### **Day‑07 — Access Reviews & Governance**  
Folder: `07-Access-Reviews/`  
Governance lifecycle, privileged reviews, app role reviews.  
Reference: [Access Reviews](ca://s?q=Explain_Access_Reviews)

### **Day‑08 — External Identities (B2B/B2C)**  
Folder: `08-External-Identities/`  
Guest onboarding, B2B governance, B2C user flows.  
Reference: [B2B](ca://s?q=Explain_Azure_AD_B2B) | [B2C](ca://s?q=Explain_Azure_AD_B2C)

### **Day‑09 — Monitoring & Analytics (KQL + Log Analytics)**  
Folder: `09-Monitoring-Analytics/`  
KQL queries, dashboards, alerts, identity anomaly detection.  
Reference: [Monitoring](ca://s?q=Explain_Entra_Monitoring)

### **Day‑10 — SC‑300 Exam Prep & Final Review**  
Folder: `10-Exam-Prep/`  
Scenario practice, domain mapping, readiness checklist.

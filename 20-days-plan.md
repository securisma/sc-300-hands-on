# 🚀 SC‑300 Hands‑On Identity Architecture Program  
A complete **20‑day enterprise identity engineering curriculum** covering Microsoft Entra ID, Zero Trust, Identity Governance, Conditional Access, PIM, Automation, Monitoring, DR/BCP, and full architecture documentation.

This repository is designed as a **portfolio‑ready**, **real‑world**, **hands‑on** identity engineering program aligned with **SC‑300 exam domains** and **enterprise IAM best practices**.

---

# 📚 Repository Structure (20 Days)

## **Day‑01 — Identity Fundamentals & Tenant Setup**  
Folder: `01-Identity-Fundamentals/`  
Covers: Tenant creation, identity basics, RBAC, core Entra concepts.

## **Day‑02 — Conditional Access Foundations**  
Folder: `02-Conditional-Access/`  
Covers: MFA, session controls, named locations, device filters.

## **Day‑03 — Identity Lifecycle Management**  
Folder: `03-Identity-Lifecycle/`  
Covers: Users, groups, roles, provisioning, lifecycle governance.

## **Day‑04 — App Registrations & Enterprise Apps**  
Folder: `04-App-Registrations/`  
Covers: OAuth2, OIDC, SAML, app roles, permissions.

## **Day‑05 — Modern Authentication Flows**  
Folder: `05-Modern-Auth/`  
Covers: Token flows, API permissions, app integration.

## **Day‑06 — Identity Protection (Risk‑Based Access)**  
Folder: `06-Identity-Protection/`  
Covers: User risk, sign‑in risk, remediation, risk policies.

## **Day‑07 — Access Reviews & Governance**  
Folder: `07-Access-Reviews/`  
Covers: Governance lifecycle, privileged reviews, app role reviews.

## **Day‑08 — External Identities (B2B/B2C)**  
Folder: `08-External-Identities/`  
Covers: Guest onboarding, B2B governance, B2C user flows.

## **Day‑09 — Monitoring & Analytics (KQL + Log Analytics)**  
Folder: `09-Monitoring-Analytics/`  
Covers: KQL queries, dashboards, alerts, identity anomaly detection.

## **Day‑10 — SC‑300 Exam Prep & Final Review**  
Folder: `10-Exam-Prep/`  
Covers: Scenarios, exam alignment, readiness checklist.

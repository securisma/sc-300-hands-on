# Day‑13 — Identity Architecture Portfolio

## 📌 Overview
Day‑13 focuses on assembling a complete **Identity Architecture Portfolio** based on your SC‑300 lab.  
This portfolio demonstrates your ability to design, implement, secure, monitor, and automate Microsoft Entra ID environments using Zero Trust principles.

You will create:
- Architecture documentation  
- Diagrams  
- Governance models  
- Security controls  
- Automation workflows  
- Evidence artifacts  
- A final professional portfolio  

---

## 1. Portfolio Structure

Create the following folder structure:

```
13-Identity-Architecture-Portfolio/
  01-Overview/
  02-Architecture-Diagrams/
  03-Identity-Governance/
  04-Conditional-Access/
  05-PIM/
  06-Identity-Protection/
  07-External-Identities/
  08-Monitoring-Analytics/
  09-Automation/
  10-Zero-Trust-Model/
  11-Final-Portfolio/
```

Each folder will contain documentation, diagrams, and evidence from your lab.

---

## 2. Create the Identity Architecture Overview

File:

```
13-Identity-Architecture-Portfolio/01-Overview/overview.md
```

### Include:
- Tenant summary  
- Identity components  
- Security baseline  
- Governance model  
- Monitoring strategy  
- Automation strategy  

### Example sections:
- **Identity Provider:** Microsoft Entra ID  
- **Authentication:** MFA, CA, Identity Protection  
- **Authorization:** RBAC, PIM, App roles  
- **Governance:** Access Packages, Access Reviews  
- **External Identities:** B2B + B2C  
- **Monitoring:** Log Analytics, KQL, Alerts  
- **Automation:** GitHub Actions + Graph API
